# Deploy notes

- `/assets/*` is served with `Cache-Control: public, max-age=31536000, immutable` (see `site/vercel.json`). Browsers and the CDN will NOT revalidate these files for a year.
- When you replace an image or video, give the new file a NEW filename (e.g. `kgm-hero-v2.mp4`) or bump a query string (`?v=N`) on every reference. Re-encoding at the same filename will keep serving the old bytes to returning visitors.
  - Hero media is versioned by filename: `kgm-hero-v2*` (landscape `.mp4/.webm`, `-sm.mp4` 480p, `-portrait.mp4/.webm` 540x960, `-poster[-portrait].jpg`, `-last[-portrait].jpg`). Any re-render becomes `kgm-hero-v3*`: rename ALL of them, then update `SMALL_JS` and the HTML in `gen/gen.py` (and the poster preload links) in one go. Never overwrite a v2 file.
  - Logo geometry/timing constants live in `site/app.js` (`GEO`, `SETTLED`, from `assets/video/hero-meta-v2.json`); update them if the video is re-cut. The DOM logo must sit exactly on the logo baked into the last frame.
  - Debugging a phone: open `/?debughero=1` and screenshot the small panel (chosen source, orientation, saveData, reduced-motion, play() result, readyState, currentTime, end-state path).
  - Images: `gen/gen.py` (logo-lockup, logo-emblem, favicons, og.jpg). `og.jpg` is no longer generated by `gen.py`; it is a managed asset.
- `styles.css` and `app.js` are cache-busted with `?v=3` in `gen/gen.py`; bump it on any change.
- Regenerate pages with `python3 gen/gen.py` (output is plain static files, no build step on Vercel).
